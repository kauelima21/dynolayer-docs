DynamoDB ORM em Python

DynamoDB sem boilerplate.
Modelo, persiste, consulta.

DynoLayer é um ORM minimalista para DynamoDB. Defina seus modelos, persista, consulte e remova dados com uma API enxuta — sem se perder em PutItem, QueryInput e ExpressionAttributeNames.

Comece a usar GitHub 
    $
    pip install dynolayer

API enxuta

.create(), .find(), .save(), .destroy(). Nada de SDK cru.

Validação built-in

Campos obrigatórios, IDs automáticos (UUID v4 ou numérico) e timestamps já vêm prontos.

Query builder

Filtros, índices secundários, paginação e batch_create sem montar expressão na mão.
