Seu primeiro model

O DynoLayer segue o padrão Active Record. Cada classe model representa uma tabela DynamoDB.

Nota: partition_key tem default "id". Para tabelas com partition key diferente, declare explicitamente: partition_key="user_id".

Parâmetros do model

  • entity: nome da tabela DynamoDB
  • required_fields: campos obrigatórios ao criar registros
  • fillable: whitelist de campos para mass assignment
  • timestamps: adiciona created_at e updated_at
  • timestamp_format: override do formato ("numeric" ou "iso")
  • auto_id: estratégia de ID automático ("uuid4", "uuid1", "uuid7", "numeric")
  • auto_id_length: tamanho do UUID truncado (16-32)
  • auto_id_table: tabela de sequências para IDs numéricos (default: "dynolayer_sequences")
  • partition_key: default "id"
  • sort_key: opcional, apenas se a tabela tiver sort key
