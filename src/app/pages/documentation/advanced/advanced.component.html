Estratégias

  • "uuid4" — UUID v4 aleatório (recomendado)
  • "uuid1" — UUID v1 (time-based + MAC)
  • "uuid7" — UUID v7 time-ordered (Python 3.14+, fallback uuid4)
  • "numeric" — inteiro incremental via tabela de sequências

Modo silencioso (raise_on_error)

A partir da v2.0, o DynoLayer opera em modo silencioso por default — exceções suprimidas, métodos retornam indicadores de falha. Acesse o erro via fail().

Boas práticas

  • Use índices nas suas queries — evite force_scan()
  • Sempre limite resultados com limit()
  • Use projeção (attributes_to_get()) para reduzir payload
  • Prefira batch operations a chamadas individuais
  • Valide dados nos seus models (override de save())
